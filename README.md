# 📊 Small Business Profitability Analysis

An interactive and animated data analytics project designed to analyze small business profitability, sales performance, discount impact, and regional trends using Python and visualization tools.

## 🚀 Project Overview

The objective of this project is to identify the key factors affecting business profitability through data analysis and visualization.

The project uses a Kaggle retail dataset to explore sales, profit, product categories, discount bands, and regional performance. An interactive dashboard presents the findings through animated charts and KPI indicators.

## 🎯 Objectives

- Analyze overall sales and profit.
- Calculate profit margins and business KPIs.
- Identify profitable and loss-making product categories.
- Analyze the impact of discounts on profitability.
- Compare business performance across regions.
- Visualize monthly sales and profit trends.
- Develop an animated and interactive dashboard.

## 📂 Dataset

**Dataset:** Superstore Dataset – Final

**Source:** Kaggle

🔗 [Download Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

The dataset includes information such as:

- Order Date
- Sales
- Profit
- Discount
- Quantity
- Category and Sub-Category
- Region
- Customer Segment

> Note: This dataset represents retail transactions and is used as a proxy for small business profitability analysis.
